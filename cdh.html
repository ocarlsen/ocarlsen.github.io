What I built at Claire Daily Health

Owen Carlsen · Nov 2026

From June 2026 I was the founder and sole engineer of Claire Daily Health, which began as a plan for a regulated telehealth brand. In October I paused the product launch. The pipelines still run, and this page describes what they do.

What runs

I built it with Claude Code, in Python, on the Anthropic, OpenAI and Gemini APIs, with jobs scheduled by launchd. The company's day-to-day work runs on LLM pipelines I designed: email and Slack triage, daily briefs, social content and PR review. That is over 100 scheduled jobs and over 10,000 model runs since late June. About half of the jobs are canaries that check the state the others leave behind.

Agents and evals

I built the company's AI voice and chat agents and an eval harness for them. An LLM judge scores each answer, and the evals require answers grounded in the company's own content, with zero-tolerance gates on fabrication, medical advice and privacy. The harness recorded 452 results, all on the chat agent.

Model upgrades

A job checks every vendor hourly for new releases, and an approved candidate runs blind against the current model on the company's own tasks. The first one moved a production model to a newer release at half the price. I wrote up how it works in Upgrading production models without guessing. I also built pinbench, an open-source CLI that runs the same blind, cost-capped A/B test on your own inputs before a job switches models.

Cost and memory

I cut the Slack agent's cost per reply by over a third by moving rarely used sections of its prompt into files it loads on demand. Each project's memory goes to the agents that read it, and a canary flags any memory store that nothing loads.

Parallel sessions

I ran many Claude Code sessions in parallel, one per project. The tooling that keeps their memory current across sessions, and lets me answer them all from one session, is open source as session-notes.

How this was written: Claude drafted from my notes; I edited the draft and checked every claim against the code and logs.
